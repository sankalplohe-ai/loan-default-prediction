# Loan Default Prediction Using Python, Data Science & Machine Learning

## Project Overview
This beginner-friendly project predicts loan default risk using Machine Learning techniques and financial borrower data.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Feature Selection
5. Model Building
6. Prediction
7. Model Evaluation

## Model Used
- Logistic Regression

## Evaluation Metrics
- Accuracy Score
- Confusion Matrix
- Classification Report

## Conclusion
This project demonstrates a beginner-level machine learning workflow for predicting loan default risk using Python and Data Science techniques.
