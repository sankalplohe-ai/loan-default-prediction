# Loan Default Prediction Using Python, Data Science & Machine Learning

## Project Overview
# Loan Default Prediction | Python, Data Science & Machine Learning

Predicts the likelihood of loan default from borrower financial data using a Logistic Regression classification model.

## Key Result

- **Accuracy:** 97%
- **F1-score:** 94%
- **Models compared:** Logistic Regression, Decision Tree, Random Forest
- **Techniques:** Feature engineering, hyperparameter tuning, ROC-AUC evaluation

## Project Overview

This project builds an end-to-end classification pipeline to assess loan default risk using borrower financial attributes. It covers data cleaning, exploratory data analysis, feature engineering, model training, and evaluation.

## Tech Stack

- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
- **Model:** Logistic Regression

## Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Feature Selection
5. Model Building
6. Prediction & Evaluation

## Evaluation Metrics Used

- Accuracy Score
- Confusion Matrix
- Classification Report (Precision, Recall, F1-score)

## Conclusion

This project demonstrates a complete supervised learning workflow — from raw borrower data to an evaluated classification model — for predicting loan default risk.
